# Visualización de Datos 2026

Repositorio del curso de Visualización de Datos.

## Estructura del repositorio
- `cuadernos/`: Cuadernos de trabajo en Python y R.
- `talleres/`: Solución a los talleres prácticos.
- `proyectos/`: Avances de los  proyecto en el aula .
- `documentos/`: Guías y bitácoras del curso.

## Lo que aprendí

1.  Aprendí a estructurar un repositorio desde cero, mantener un historial claro de commits explicativos y configurar archivos como `.gitignore` y `.gitattributes` para mantener el entorno de trabajo limpio.
2.  Entendí el comportamiento de Git al clonar repositorios ajenos y por qué falla un `push` sin permisos, comprendiendo la importancia de los *forks* para la colaboración en proyectos abiertos.
3.  Interioricé la regla de sincronización constante (`git pull` al iniciar y `git push` al finalizar), asegurando que el trabajo sea independiente del computador físico y esté protegido en la nube.
